# ai-docs — notes for AI agents (not published)

This folder holds reference material for AI agents (and humans) working on the
site. **It is excluded from the Jekyll build** (see the `exclude:` list in
`_config.yaml`), so nothing here ever appears on the public website. Edit freely.

## Guiding principle — work within the template

This is the **Greene Lab "Lab Website Template."** Its whole value is that content
is authored as Markdown + Liquid includes with almost no custom code, and the
citation pipeline + CI are already built. When making changes:

- **Prefer the existing components, data files, and config** over writing new
  code. Almost everything (featured lists, filtered lists, restyled lists,
  featured citations, member cards) is achievable by passing parameters to
  existing `_includes/*.html` or editing `_data/*.yaml`.
- **Don't add new HTML/JS/SCSS or plugins unless there's a clear reason** the
  template genuinely can't do it — and if you do, say why. Extra custom code is
  the main way this template gets hard to maintain and hard to upgrade.
- **Never hand-edit `_data/citations.yaml`** — it's regenerated by CI.
- **Don't break the build.** Keep changes reversible and scoped.

## Contents

- **`template-reference.md`** — how the template works (components, data files,
  citation pipeline) and links to the official machine-readable docs
  (`llms.txt` + per-page `.md`). Fetch those for detail instead of guessing.
- **`lab-research.md`** — source-checked notes on Sam and the lab's research
  (bio, awards, mission, research themes, flagship papers) for writing site copy.
